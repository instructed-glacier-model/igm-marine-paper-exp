# Unconfined ice shelf: calving-front verification (paper Sect. 4.1, Fig. 2)

The flow-band ice shelf of Albrecht et al. (2011, Sect. 4): fed at x = 0 with 600 m of ice at 300 m yr⁻¹, uniform
rate factor (B₀ = A^(−1/n) = 1.9 × 10⁸ Pa s^(1/3)), no basal friction, accumulation or melt. The spreading rate of
Weertman (1957) gives steady thickness and velocity profiles independent of the front position and, by integration
along the velocity profile, the trajectory of the front for any calving rate (`prep/common.py`). Both front schemes
of IGM (sub-grid and level set) are run with every calving option active on a flowline, and compared with these
analytic references.

| | Albrecht et al. (2011) | IGM setting |
|---|---|---|
| domain | 505 km flowline, periodic across flow | 500 km × 2 nodes; iceflow `periodic_ns`; thk `top`/`bottom: symmetric` |
| inflow | H₀ = 600 m, u₀ = 300 m yr⁻¹ at x = 0 | iceflow `bc.dirichlet.left: [300, 0]`; thk `boundary.left: dirichlet` (exterior thickness H₀) |
| ice | ρ = 910, ρ_w = 1028 kg m⁻³, B₀ = 1.9 × 10⁸ Pa s^(1/3), n = 3 | `ice_density`, `water_density`, `thk.ratio_density` 0.885214, `arrhenius` 4.600806 MPa⁻³ yr⁻¹ |
| bed | deep enough to float | −5000 m, sea level 0; no friction |
| stress balance | SSA with the calving-front stress condition | MOLHO (N_z = 2, Q1 elements), floating-front pressure, Newton–CG in float64, cold-started at every step |
| front | sub-grid | `thk.front.method: sub_grid` or `level_set`, or none (control) |
| calving | front ice thinner than 250 m removed | `thk.front.min_thickness: 250` (advance runs); `calving_rate` process (rate runs) |
| time step | adaptive CFL | `time.cfl: 0.5` (including the calving rate), at most 20 yr |
| resolution | 10, 5, 2.5 km | 10, 5, 2.5 km |

## Runs

| Run | What | Years |
|---|---|---|
| `adv_<scheme>_<res>` (10 km, 5 km, 2.5 km) | advance from a two-cell shelf to the steady state under the 250-m minimum-thickness criterion; Fig. 2a–d | 500 |
| `advance_<scheme>_5km`, `retreat_<scheme>_5km` | prescribed front velocities +200 / −300 m yr⁻¹ (`ice_speed` law) from the 5-km steady state; Fig. 2e | 300 |
| `vm_<scheme>_5km` | von Mises calving, σ_max = 0.09 MPa; Fig. 2f | 300 |
| `const_<scheme>_5km` | constant calving rate 800 m yr⁻¹ (the water-depth law on this uniform bed); numbers of the text | 300 |
| `adv_none_5km` | control without a front scheme (the front disperses); text | 300 |

`<scheme>` is `sub_grid` or `level_set`. The rate runs start from `data/restart/adv_<scheme>_5km.nc`, the last frame
of the corresponding advance run (`make_restart.py`); the shipped files are those of the paper's runs.

## Data (`data/`)

`albrecht_{10km,5km,2.5km}.nc` (bed, sea level, initial two-cell shelf; `prep/make_inputs.py`) and the two restart
files. There are no third-party data: the references are analytic (`prep/common.py`, after Albrecht et al., 2011,
doi:[10.5194/tc-5-35-2011](https://doi.org/10.5194/tc-5-35-2011), and Weertman, 1957).

## Software and hardware

- IGM `dev` (see `../../README.md`).
- One NVIDIA RTX 4090 (24 GiB), driver 535.161.07. Each run takes 3–8 min; all 15 about 70 min of GPU time.
- User modules in `user/`: `albrecht_ts` (output: front position, volume, inflow, calved volume, mass-budget
  residual per step) and `thin_ice_calving` (control run only).

## Reproduce

Run from this folder, in an environment with IGM.

| step | command | output | cost |
|---|---|---|---|
| 0 (optional) inputs and experiments | `python prep/make_inputs.py && python prep/make_experiments.py` | `data/albrecht_*.nc`, `experiment/*.yaml` (shipped; the generator also writes the 1.25-km and 1-yr-step variants not used in the paper) | seconds |
| 1 runs | `./run.sh` | `outputs/<run>/` (`output.nc`, `albrecht_ts.csv`), `data/restart/` | ~70 min, 1 GPU |
| 2 numbers of the text | `python analysis.py` | `results/summary.md`, `results/summary.csv` | seconds |
| 3 figure data | `python make_figure_data.py` | `../figure/data/*.csv` (shipped) | seconds |
| 4 figure | `python ../figure/make_figure.py` | `../figure/fig_02_albrecht_verification.{pdf,png}` | seconds |

`run.sh` runs steps 1–3 in sequence. The numbers of Sect. 4.1 come from `results/summary.md`: the profile errors
(`H_maxrel`, `u_maxrel`: 0.2 % and 0.4 % at 2.5 km, 1.5 % and 0.6 % at 10 km), the steady fronts (`x_front_km`:
153.0 / 145.0 km at 10 km for the sub-grid / level-set schemes, 148.0 / 148.2 at 5 km, 146.7 / 146.9 at 2.5 km, against
144.45 km), the overshoot of the advance (`front_maxerr_km`, up to 16 km), the errors of the rate laws
(`front_maxerr_km`, at most 0.46 km) and the mass-budget residual (`mass_residual_rel`, ≤ 3 × 10⁻⁷).

## Layout

```
prep/              common.py (constants, analytic solutions), make_inputs.py, make_experiments.py, methods/fast.yaml
experiment/        the 15 run configurations (generated by prep/make_experiments.py; self-contained)
user/              user modules (code/ and conf/): albrecht_ts, thin_ice_calving
data/              inputs and restart files
run.sh             the runs in sequence
make_restart.py    last frame of an advance run -> data/restart/<run>.nc
analysis.py        runs -> results/summary.md (numbers of the text)
make_figure_data.py  runs -> ../figure/data/*.csv
```
